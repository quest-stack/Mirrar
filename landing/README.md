# Auto Pailot Tester - Landing Page

> Next.jsで作成されたランディングページ

## 🚀 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev
```

http://localhost:3000 で確認できます。

## 📦 ビルド

```bash
# 静的ファイルとしてエクスポート
npm run build
```

`out/` ディレクトリに静的ファイルが生成されます。

## 🌐 Vercelデプロイ

1. Vercelアカウントでログイン
2. 「New Project」を選択
3. このリポジトリをインポート
4. Root Directoryを `landing` に設定
5. 「Deploy」をクリック

または、Vercel CLIを使用：

```bash
npm install -g vercel
vercel
```
