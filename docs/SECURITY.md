# 🔒 セキュリティガイドライン

## テストデータの取り扱い

### ⚠️ 絶対にやってはいけないこと

1. **本番環境のパスワードを使用しない**
   ```
   ❌ 悪い例: 実際に使っているパスワード
   ✅ 良い例: testpassword123
   ```

2. **実在するメールアドレスを使用しない**
   ```
   ❌ 悪い例: yourname@gmail.com
   ✅ 良い例: test@example.com
   ```

3. **本物のクレジットカード情報を入力しない**
   ```
   ❌ 悪い例: 実際のカード番号
   ✅ 良い例: テストカード番号（決済サービスのドキュメント参照）
   ```

4. **APIキーやトークンを含めない**
   ```
   ❌ 悪い例: 本番環境のAPIキー
   ✅ 良い例: テスト環境のAPIキー、またはモックデータ
   ```

### 推奨されるテストデータ

#### メールアドレス
```
test@example.com
user@test.com
demo@localhost
```

#### パスワード
```
testpassword123
password123
Test1234
```

#### 名前
```
山田太郎
テストユーザー
Test User
```

#### 電話番号
```
000-0000-0000
090-1234-5678（ダミー）
```

## プライバシー保護

### データの保存場所

すべてのデータは**ローカル**に保存されます：

```
Windows: C:\Users\[ユーザー名]\AppData\Roaming\auto-pailot-tester\
Mac: ~/Library/Application Support/auto-pailot-tester/
Linux: ~/.config/auto-pailot-tester/
```

### 保存されるデータ

- **テスト定義**: テストのステップ、セレクター等
- **スクリーンショット**: テスト実行時のスクリーンショット
- **動画**: テスト実行の録画（オプション）
- **実行履歴**: テスト結果のログ

### 保存されないデータ

- パスワード（マスクして保存）
- APIキー
- 個人情報（自動で警告）

## AI連携時のセキュリティ

### プロンプト送信前の確認

AIツール（Claude Code、Cursor等）にプロンプトを送信する前に、以下を自動チェックします：

- ✅ パスワードが含まれていないか
- ✅ APIキーが含まれていないか
- ✅ メールアドレスが含まれていないか
- ✅ クレジットカード情報が含まれていないか

### 警告が表示されたら

機密情報が検出された場合、以下のような警告が表示されます：

```
⚠️ 警告: このプロンプトに機密情報が含まれている可能性があります

検出された項目:
• パスワードが含まれています
• メールアドレス: yourname@example.com

推奨事項:
• テスト用のダミーパスワードを使用してください
• 実在しないテスト用メールアドレスを使用してください

このままAIツールに送信しますか？
[キャンセル] [編集] [送信]
```

**推奨**: 「編集」をクリックして、機密情報を削除してから送信してください。

## コードのセキュリティ

### XSS（クロスサイトスクリプティング）対策

- すべてのユーザー入力は自動でサニタイズされます
- HTMLタグは無効化されます
- スクリプトの実行を防ぎます

### SQLインジェクション対策

- パラメータ化クエリを使用
- ユーザー入力を直接SQL文に埋め込まない
- すべての入力を検証

### ファイルアクセス制限

- パストラバーサル攻撃を防ぐ
- 許可されたディレクトリ外へのアクセスを禁止
- ファイルパスを検証

## セキュリティのベストプラクティス

### テスト作成時

1. **常にテスト用のダミーデータを使用**
   - 本番データは絶対に使わない
   - 実在しない情報を使う

2. **ローカル環境でテスト**
   - 可能な限りローカル環境（localhost）で実行
   - 本番環境へのアクセスは最小限に

3. **スクリーンショットに注意**
   - 機密情報が写り込んでいないか確認
   - 不要なスクリーンショットは削除

### データ管理

1. **定期的な削除**
   - 古いスクリーンショット・動画は定期的に削除
   - 設定から自動削除を有効化（推奨: 7日後）

2. **バックアップ**
   - テストデータをバックアップする場合は暗号化
   - クラウドストレージに保存する場合は注意

3. **共有時の注意**
   - テストを他の人と共有する前に、機密情報がないか確認
   - エクスポート時に自動で機密情報をマスク

## トラブルシューティング

### 「機密情報が検出されました」と表示される

**原因**: テストデータに本番環境のような情報が含まれています

**対処法**:
1. テストデータをダミーデータに変更
2. パスワードを「testpassword123」等のシンプルなものに
3. メールアドレスを「test@example.com」に

### プロンプトが長すぎてAIツールにコピーできない

**原因**: HTMLスナップショットが大きすぎる

**対処法**:
1. HTMLスナップショットの範囲を限定
2. 不要な部分を削除してから送信
3. セレクターだけをAIツールに送信
